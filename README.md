# Agent Flow Studio

Multi-agent orchestration framework for automating full-stack Angular development workflows. 4 agents, 2 phases, 1 learning loop — orchestrated by Claude Code.

## Structure

```
.claude/agents/     — Agent SKILL.md definitions (SRS, Implementation, AI Review, DevOps)
.claude/skills/     — Orchestrator skill definitions
.claude/hooks/      — Deterministic hook implementations (JS)
.claude/memory/     — Control-plane + persistent memory (JSON, git-versioned)
designs/            — HTML spec documents (source of truth for architecture)
docs/srs/           — SRS artifacts per feature (generated by SRS Agent)
scripts/            — Utility scripts
```

## Pipeline

```
Feature Brief → SRS Agent → [Auto QA] → [Human Approval] → Implementation Agent (TDD)
→ CI + AI Review Agent → [Gate] → DevOps Agent → [Human Go/No-Go] → Gradual Rollout
→ Learning Loop (retrospective → patterns → schema evolution)
```

## Getting Started

0. Enable the secret-blocking pre-commit hook (once per clone): `git config core.hooksPath .githooks`
1. Read the design specs: `python3 -m http.server 8731` → open `http://localhost:8731/designs/full-system-unified.html`
2. Review agent definitions in `.claude/agents/`
3. Start a feature by providing a feature brief — the Orchestrator (CLAUDE.md) routes it through the pipeline
