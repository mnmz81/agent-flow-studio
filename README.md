# Agent Flow Studio

Multi-agent orchestration framework for development workflows.

## Structure

```
agents/       — Agent definitions and logic
skills/       — Reusable skills for agents
designs/      — HTML design files (agent flow diagrams)
flows/        — Flow configurations (agent pipelines)
docs/         — Documentation
scripts/      — Utility scripts
```

## Getting Started

1. Place your HTML design files in `designs/`
2. Define agents in `agents/`
3. Define skills in `skills/`
4. Wire them together in `flows/`
