🔄 Continuous Learning Loop — triggered after every ship
System improves with every feature
Retrospective Agent compares SRS intent vs. shipped reality. Findings feed Pattern Extraction → SRS Schema Evolution. Agent Scoring is deferred until sample sizes are meaningful. All learnings go to Long-term Memory — read-only, no auto-prompt changes.
