⚙ Deterministic CI — no agent, no skills
The v1 "Automated Review Agent" and its 4 skills (eslint-prettier-gate, security-audit, coverage-threshold-gate, bundle-size-check) are gone. These checks are deterministic, so they run as a Stop hook + GitHub Actions — there is nothing for an LLM to decide. They appear here only to mark that the capability still exists, just not as an agent.
